# Student Performance Analytics System

## 1. Project Overview
This project analyzes student academic performance using Python. It calculates total marks, average marks, grades, and pass/fail status.

## 2. Technologies Used
- Python
- Pandas
- NumPy
- CSV dataset

## 3. Project Features
- Reads student records from a CSV file.
- Calculates total and average marks.
- Assigns grades and pass/fail status.
- Calculates class average and identifies the class topper.
- Analyzes attendance and subject-wise performance.
- Calculates department-wise student count and average.
- Displays the top 3 students.
- Exports the final report to a CSV file.

## 4. Output
The system analyzes 15 student records and saves the results in `Student_report.csv`.

## 5. Conclusion
This project demonstrates how Python, Pandas, and NumPy can be used to analyze student performance and generate useful reports.
